# Security & private information

Do not post API keys, passwords, authentication headers, connection settings, private hostnames, or unredacted library reports in public issues.

If a credential is exposed, revoke or rotate it at the service that issued it. Removing it from a later commit or comment does not make the old credential safe to reuse.

## Reporting a vulnerability

If GitHub offers a **Report a vulnerability** option in this repository's Security tab, use that private channel. If it is unavailable, open an issue asking the maintainer for a private reporting channel **without including exploit details, credentials, or private data**.

This is an alpha project without a published security-support schedule. Keep your checkout current and review changes before applying file or metadata operations to your library.
